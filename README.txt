CARA UPDATE DI GITHUB LEWAT HP:
1. Buka https://github.com/viajingga/jingga-arka
2. Buka index.html. Tekan ikon pensil (Edit this file) atau menu tiga titik jika ikon pensil tidak terlihat.
3. Cara paling mudah biasanya: buka file index.html di ZIP ini sebagai teks, salin seluruh isi, lalu tempel menggantikan isi index.html di editor GitHub.
4. Tekan Commit changes untuk menyimpan. Tunggu GitHub Pages memperbarui website.

PENTING: jangan mengganti index.html jika belum berhasil menyalin kode versi baru ke editor. Simpan salinan file lama sebagai cadangan.

FOTO: input foto di galeri hanya pratinjau pada perangkat/browser yang sedang dibuka, tidak otomatis menyimpan foto untuk semua pengunjung. Agar foto muncul pada link publik, unggah file gambar ke repository lalu ubah kode HTML agar menggunakan nama file gambar tersebut.
MUSIK: unggah file musik yang kamu punya izin untuk gunakan ke repository dengan nama song.mp3. Tombol play mengacu ke nama itu.
PASSWORD: pengunci sederhana di sisi browser, bukan keamanan sungguhan.
